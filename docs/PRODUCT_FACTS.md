# YadaCall — что у нас есть

Фактический лист для лендинга, сайта и описаний. Только то, что реально работает в 0.1.1, и цифры, которые мы сами намерили. Цифры скорости — на MacBook Pro M1 Pro 16 ГБ.

## Коротко

- Записывает созвоны в две дорожки — «я» (микрофон) и «собеседники» (системный звук) — и расшифровывает их **прямо на компьютере, во время звонка**.
- Звук никогда не покидает компьютер. Без аккаунтов, без телеметрии, без бота в звонке.
- Бесплатно, open source (MIT): https://github.com/limeflash/yadacall
- macOS 14.2+ (Apple Silicon), Windows 10/11 x64, Linux x64 (Ubuntu 24.04+).
- Последняя версия: 0.1.1 (первый публичный релиз, 13 октября 2026).

## Запись

- Две дорожки без виртуальных драйверов (BlackHole и т. п. не нужны): Core Audio taps на macOS, WASAPI loopback на Windows, PulseAudio/PipeWire на Linux.
- Работает с любым звонком: Google Meet, Zoom, Telegram, Teams, Slack, Discord, Телемост — в браузере или в приложении. В звонок ничего не подключается, собеседники ничего не видят.
- Запись переживает падение приложения (теряется не больше пары секунд) и смену наушников посреди звонка.
- С Bluetooth-наушниками (AirPods и т. п.) автоматически пишет встроенный микрофон, чтобы звонок не проваливался в «режим гарнитуры» с плохим звуком у всех.
- Пауза, закладки во время звонка (⌥⇧M), старт/стоп горячей клавишей (⌥⇧R), запись из трея, мини-плеер поверх окон.
- Предупреждает, если одна из дорожек молчит (не тот микрофон, звонок на телефоне).
- Импорт готовых записей: аудио и видео файлы любых популярных форматов.

## Расшифровка

- Полностью на устройстве, работает без интернета.
- Русский — **GigaAM v3** (Сбер), с пунктуацией и заглавными буквами: **20–26× быстрее реального времени** на M1 Pro, модель весит ~230 МБ, загружается за ~0,6 с.
- 25 европейских языков (включая русский и английский) — **Parakeet TDT v3** (NVIDIA): ~22× быстрее реального времени.
- **Живая расшифровка во время звонка** — реплики появляются по ходу разговора; после «Стоп» текст готов **за секунды**, а не за минуты.
- Час звонка обрабатывается за ~2–3 минуты, если расшифровывать после.
- Словарь терминов: исправляет написание продуктов и жаргона («Google Mit» → «Google Meet», «джира» → «Jira»), встроенный список + свои слова.
- Фильтры «галлюцинаций» распознавания и эха (если без наушников голос собеседника попадает в микрофон).
- «Распознать заново» — пересобрать расшифровку из сохранённого звука новой моделью.

## Кто говорит

- Свои реплики и реплики собеседников разделены по дорожкам — в звонке один на один ошибок нет.
- В групповых звонках разметка голосов на устройстве (модель CAM++), склейка одного человека, если его раскидало на несколько «спикеров».
- Узнаёт знакомые голоса по прошлым встречам и подписывает их автоматически.
- Имена подсказываются из приглашения в календаре.

## Итоги и задачи

- О чём встреча, договорённости, задачи (кто, что, к какому сроку), открытые вопросы — у каждого пункта таймкод, клик ведёт в момент разговора.
- Где считать итоги — на выбор:
  - **на компьютере** — Gemma 4 (Google) через llama.cpp, ~35–48 ток/с на M1 Pro, итоги короткой встречи ~40 с;
  - **через Ollama** — локальные модели или облачные модели по подписке Ollama (итоги за ~6–10 с), без ключей;
  - **через API** — Ollama Cloud, Claude, OpenRouter, LM Studio, любой OpenAI-совместимый сервер;
  - **без итогов** — только расшифровка.
- В облако уходит только текст расшифровки и только если выбран облачный провайдер; звук — никогда. Приложение показывает, что именно ушло («6 фрагментов текста в Claude, аудио — нет»).
- Шаблоны: обычная встреча, стендап, 1:1, интервью.
- «Скопировать для Claude» — транскрипт + команда разбора в буфер.

## Поиск и вопросы

- Поиск по всем встречам: полнотекстовый (с русской морфологией) + по смыслу (локальная модель эмбеддингов, ~130 МБ), объединены.
- «Вопрос ко всем встречам»: ответ с цитатами [1][2], каждая ведёт в нужную встречу и момент.
- Задачи из всех встреч — на одном экране, с отметками «сделано».

## Календарь и звонки

- Google Календарь, **несколько аккаунтов сразу** (рабочий, личный…), только чтение.
- Лента «Сегодня»: следующий звонок с обратным отсчётом, накладки между аккаунтами.
- Напоминание за 1/2/5 минут: «Войти и записать» — открывает Meet **в нужном аккаунте** и сразу начинает запись.
- Политика на аккаунт: спрашивать / всегда записывать / никогда.
- Замечает звонки не из календаря (например, Meet по ссылке) — «Звонок в Brave — записать?».
- Любой календарь по ICS-ссылке без входа: Яндекс, Outlook, iCloud.
- В каталоге подключений «скоро»: Zoom, Teams, Discord, Telegram, Slack.

## Модели: «потянет ли?» до скачивания

- Для каждой модели — прогноз по твоему железу до загрузки: «≈ 26× реального времени», «≈ 39 ток/с · 3,5 из 16 ГБ», «Не поместится», «Слишком медленно».
- Приложение само меряет процессор, память, пропускную способность, GPU/Neural Engine; после скачивания делает реальный замер и уточняет прогнозы.
- Загрузка в 6 потоков (≈ 2× быстрее), докачка с места обрыва, проверка sha256, зеркало hf-mirror.
- Модели по умолчанию маленькие: расшифровка ~230 МБ, поиск ~130 МБ; локальные итоги (Gemma 4 E2B) ~2,8 ГБ — по желанию.

## Приложение

- Установщик: **~21 МБ** (macOS .dmg), ~16 МБ (Windows .exe); приложение ~42 МБ. Без ffmpeg, Python и Electron — Rust + системный WebView.
- Трей / строка меню: таймер записи, ближайший звонок, последние встречи.
- Тёмная/светлая тема, выбор акцентного цвета, интерфейс на русском и английском.
- Автообновление прямо в приложении.
- Встречи хранятся простыми файлами: папка на встречу с `transcript.md`, `transcript.json`, итогами и звуком (FLAC). Хранение звука: не хранить / 7 / 30 дней / всегда — текст и итоги остаются.
- Экспорт в Markdown и JSON.

## Приватность

- Звук обрабатывается только на компьютере.
- В сеть уходит: загрузка моделей и обновлений; запросы к календарю (если подключён, только чтение); текст расшифровки — только при облачном провайдере итогов.
- Телеметрии и аналитики нет. Аккаунт не нужен.
- Ключи API и токены — в системной связке ключей (Keychain / Credential Manager).

## Технологии (для раздела «под капотом» / open source)

Rust, Tauri 2, Svelte 5, ONNX Runtime, llama.cpp, SQLite (FTS5 + sqlite-vec). Модели: GigaAM v3 (Сбер), Parakeet TDT v3 (NVIDIA), Silero VAD, CAM++ (3D-Speaker), multilingual-E5, Gemma 4 (Google). Сборки для трёх ОС собираются в GitHub Actions.

## Ограничения (честно)

- Сборки пока без подписи Apple/Microsoft: на Mac при первом запуске — правый клик → «Открыть», на Windows — SmartScreen «Выполнить в любом случае».
- macOS: только Apple Silicon (Intel не поддерживается), macOS 14.2+.
- Вход в Google-календарь сейчас в тестовом режиме у Google (ограниченный круг аккаунтов) — до прохождения проверки; ICS работает у всех.
- Linux-сборка требует Ubuntu 24.04+ или аналог.

## Бренд и ассеты

- Дизайн-система Mistgate, тёмная тема первая. Акцент по умолчанию — мятный `#7dd3a0`; пастели: лавандовый `#b8acf2`, небесный `#8ec8ea`, песочный `#dcc68c`, розовый `#e6a6b0`, шалфей `#b0cc90`. Фон `#0c0c0e`, поверхности `#141417` / `#1d1d22`.
- Шрифты: Onest (текст), JetBrains Mono (цифры, таймкоды).
- Маскот: котик в наушниках (слои PNG — голова, наушники, глаза — анимация: моргает, оглядывается, наушники покачиваются).
- Логотип: «yada**call**» (вторая часть акцентным цветом) + котик.
- Скриншоты есть для 16 экранов: итоги встречи, расшифровка, запись (котик ждёт / идёт запись с визуализатором), список встреч, вопрос ко всем встречам, задачи, настройки, модели с прогнозом, первый запуск, трей macOS и Windows, календарь, подключения, аккаунты Google, напоминания перед звонком.

## Сайт на GitHub Pages: стек

- **Astro** (статическая сборка) в папке `site/` репозитория; деплой GitHub Actions (`actions/deploy-pages`) на каждый пуш в `main`. Адрес `limeflash.github.io/yadacall` или свой домен (CNAME).
- Почему Astro: выдаёт чистый HTML/CSS без лишнего JS, легко принимает вёрстку из Claude Design (HTML/CSS переносится в `.astro`-компоненты почти как есть; интерактив — островками на Svelte, как в приложении), несколько страниц и RU/EN «из коробки», Markdown для политики конфиденциальности.
- Если в Claude Design получится одна статичная страница — подойдёт и просто `index.html` + CSS без сборщика; Astro понадобится, когда появятся `/privacy`, `/en/` и т. п.
- Страницы, обязательные для проверки Google OAuth: **главная** и **политика конфиденциальности** (RU + EN) на одном подтверждённом домене; ссылка на политику — в футере.
- Кнопки «Скачать» — с определением ОС посетителя и ссылками из GitHub API (см. выше), с запасной ссылкой на `releases/latest`.
- Шрифты Onest и JetBrains Mono — с собственного хостинга (без Google Fonts на сайте приватного приложения).
